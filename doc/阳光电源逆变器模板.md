# 阳光电源逆变器模板

## 已确认范围

依据《户用及工商业光伏并网逆变器通信协议》V1.1.78（2024-09-14），新增 RTU/TCP 共用内置模板。共 73 点：28 个测量及反馈点、37 个 BOOL 状态点、1 个故障码点、7 个写控制点。保留现有华为模板，不加入设备信息、MPPT、组串、故障时间、PID、SVG 或曲线参数。

电网频率仅保留 5148（0.01 Hz），总发电量仅保留 5144-5145（0.1 kWh）。地址按文档 1 基记录，应用时按目标连接地址基准换算；32 位采用低字在前 LH，每个字内高字节在前 AB。来源记录原 PDF 文件名、SHA256 和物理页码，不复制 PDF 到仓库。

## 状态语义与接口

5038 的 12 种工作状态、5140 的 7 种逆变器状态、5141 的 4 种逆变器状态分别按完整原始值相等生成 BOOL，共 23 点；5081-5082 按已定义 bit 生成 14 点。不同来源使用名称前缀，不额外保留同地址整字状态。

为支持枚举遥信，共用 Modbus Point 新增可选 `enum_value`（协议字段 18）。仅 BOOL、0x03/0x04 寄存器读取允许该字段；与 `bit_index` 互斥。先按字节序、字序拼接无符号原始值，再比较是否等于指定值；枚举 0 是有效配置，不代表未设置。1 个寄存器范围为 0-65535，2 个寄存器为 0-4294967295。同地址、同长度、不同枚举值允许共存，重复映射和整字冲突继续拒绝。旧模板不填写该字段，行为保持原样。

模板导入、应用、点位编辑/复制、个人模板保存和 Rust DTO 均保留该字段。使用枚举遥信需要匹配新增字段的下位机版本；旧下位机缺少选择器时应拒绝该点表，不能默认为 bit 0。

## 控制与适用条件

7 个控制点使用 0x06 单寄存器写：开/关机 5006、限功率开关 5007、限功率百分比 5008、无功调节模式 5036、无功比例设置 5037、限功率实际值 5039、限无功实际值 5040。控制点默认不选，不参与采集轮询，也不在模板应用时执行。

限功率开关 0xAA=使能、0x55=关闭；无功调节模式 0x55=关闭、0xA1=功率因数、0xA2=无功比例、0xA3=Q(P)、0xA4=Q(U)；开/关机 0xCF=开机、0xCE=关机。通过独立控制编排先写使能/模式，再用执行触发值写目标值；模板不自动创建编排或路由。

输出电压名称依输出类型解释；单相仅第一路电压、电流有效。电表功率需已连接智能电能表，负载功率受机型限制。SG5.5RS-JP 不支持的扩展点及国内电网专用状态均记录条件并默认不选。故障码仅在工作状态 0x5500/0x9100 时有意义，按数值保留。限值范围需按具体机型确认。

## 验收与边界

测试先覆盖枚举 0、互斥和范围验证、同址多状态无冲突、个人模板往返、73 点数量及精确地址/倍率/端序、写点不进入读取计划，再实现字段传递和解码。运行模板相关回归、前端构建、相关 lint 和 Rust 测试；下位机按当前环境执行可用的轻量检查，不搭建工具链或自行使用远端。

本次不包含真机通信或控制验收。通用采集层尚无厂商无效数值哨兵配置：不支持点返回全 F 或最大正数等值时不能仅凭模板转换为坏质量，现场应按型号选择支持点。通信质量沿用现有模块行为。

## 本次验证结果

工作流 360 项、离线 74 项、桌面 Rust 105 项通过，严格 ESLint 和生产构建通过。测试覆盖内置模板数量与精确映射、所有 73 点共同应用、两种地址基准、状态相等/位解析、枚举 0 的 DTO 与个人模板往返、控制点不参与读取计划。独立对照 PDF 复核了字段与状态定义，补齐两处紧急停机的硬件干接点条件。

共享协议 RTU/TCP 描述符编译通过，下位机公共解码函数独立 Clang 编译运行通过；新增点表、RTU 单点/区间以及 TCP 读取 GTest 尚未编译执行，当前 Windows 工作机没有完整下位机 Linux 依赖环境。本次未访问远端或设备。

全仓 Rust 格式检查仍报告其他模块的既有差异，未进行批量格式化；本次新增块已按现有风格整理，暂存差异检查通过。
