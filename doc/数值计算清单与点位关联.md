# 数值计算清单与点位关联

## 已确认范围

- 页面采用清单内编辑；分组在顶部切换，一次展开一条计算项，不使用计算项编辑弹窗。
- 输入行选择已有点位或常量；聚合运算的每一行是独立输入槽位，删除中间行后保留其余行的来源关系。
- 输出允许关联多个已有目标点，也允许仅生成结果点。已有多来源输入完整回显，未经用户修改不缩减。
- 选点只改变草稿；“保存计算与关联”统一提交。切换项、切组或关闭编辑前保护未保存修改。
- 重命名、变更运算、删除输入时迁移该项关联；删除计算项清理其路由。其他项、连接的路由保持不变。
- 复用现有 Calc 与 DataCenter 接口，不修改下位机、模拟器或独立测试上位机。

## 保存及异常边界

1. 打开编辑器时读取最新配置、全部路由、连接与标签目录。路由加载失败不能当作无绑定；禁止保存关联，允许重试加载。
2. 保存前比对最新分组配置，发现外部变更则保留草稿并提示重新加载，避免覆盖。
3. 停止运行中的分组功能，再保存计算配置；下位机保存可能自动运行，写路由前再次核对并停止分组功能。
4. 以增量方式建立所需路由、解除旧路由，绝不使用全局覆盖。配置与路由属于多步骤提交，不宣称原子事务。
5. 路由同步失败时明确显示“计算已保存，路由同步失败”，保持编辑草稿和重试计划，阻止继续修改或切换导致计划丢失。
6. 重试读取最新配置，确认仍与已保存版本一致，仅重试路由及恢复运行；不重复保存计算。原来停止的分组保持停止。
7. 恢复运行失败单独报告，可重试恢复；不能把配置保存成功视为计算已正常运行。

## 验收条件

- 两个普通输入、NOT 单输入、SUM/AVERAGE 多输入、常量及原有校验继续可用。
- 一个来源对应一个聚合槽位；结果可对应多个目标；已有路由回显和再次保存均不丢失。
- 重命名计算项、删除聚合中间行、更换来源、点位改常量、删除计算项均只改变本项关联。
- 未保存草稿不产生路由 API 调用；不触发任何设备或服务器部署。
- 配置失败、路由新增失败、路由清理失败、恢复运行失败、外部配置变更分别有确定性验证。
- 浏览器验证清单展开编辑、点位搜索、保存、失败重试和窄窗口布局；生产构建、lint 与相关单元测试通过。
