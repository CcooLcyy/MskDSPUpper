# 平台远程访问与内置 SSH

契约固定为 `MskDSPPlatformProto/platform/v1/remote.proto`，镜像位于 `src-tauri/proto-platform-agent/platform/v1/remote.proto`。登录访问令牌仅在 Rust 中使用。

启用远程访问前，须在平台登录设置中配置平台的 HTTPS/TLS 地址，并使用可信证书。新远程访问拒绝公网及局域网 HTTP，只有 `127.0.0.1`、`localhost`、`[::1]` 本机测试允许明文。本次不改变已有软件仓库固定地址或既有登录行为。

模块操作页选择授权设备后切换远程模式。管理服务和模块通道按逻辑名称建立环回 TCP 适配器，不拨号设备返回的现场地址。普通页面恢复直连地址不得改变远程选择，只有明确返回直连才会切换。模式变化递增代次、取消旧监听和隧道，过期地址响应不得回写。

高级配置中已有的下位机升级 SSH 流程保留独立连接目标，本次平台远程模式仅接入普通模块 gRPC 与新增内置终端。

每条环回连接创建独立 OpenTunnel，发送 open 后等待 ready；有界队列 8 帧、单帧最多 64 KiB、打开 15 秒、发送阻塞 30 秒。半关闭只关闭一个方向；错误、模式切换、平台退出或授权失效终止隧道，不重放字节。

SSH 使用独立 ssh 服务隧道和 russh 客户端、xterm 显示。首次握手展示 SHA256 指纹并要求确认，信任以平台地址及设备 ID 固定；变化时拒绝。账号密码只在本次连接内存中使用，终端内容不进入日志或持久化。终端关闭、切换设备、退出登录会取消会话。

本地检查覆盖模式选择、协议状态机、半关闭、取消、主机身份，前端类型构建及 lint。现场设备 SSH、跨公网网络抖动及真实模块控制需另行联调，不能以本地检查宣称现场验收。

## 使用与验证记录（2026-10-20）

1. 在平台登录设置填写 HTTPS 地址并登录，在模块操作页刷新平台授权设备。
2. 选择在线设备，点击“连接所选设备”；原模块管理、配置页面通过对应服务隧道访问设备。
3. 点击“SSH 终端”，输入设备 SSH 账号密码并登录，首次连接必须核对并确认主机指纹。调整窗口会同步终端大小；断开、关闭窗口、切换设备或返回直连都会结束本次终端。
4. 如需现场连接，点击“返回现场直连”，使用原 ModuleManager 地址。程序不保存终端密码和正文；已确认的主机指纹保存在运行数据目录 `remote-ssh-hosts.json`。

本地通过：workflow 435 项、offline 89 项、Rust 160 项；前端 build、严格 lint、`git diff --check` 通过。新增 Rust 行为测试使用随机 localhost tonic 及真正的本地 russh SSH 服务，覆盖 100 KB 二进制、半关闭尾部、半关闭后的撤销、非法帧、服务动态加入、服务隔离、模式及退出取消、预先取消、HTTPS 约束、主机指纹确认/拒绝/变更、SSH 登录/resize/退出尾部，以及终端输出最多积压 8 块的背压。新增前端行为测试确认会话 ID 返回前已消费的输出能补还额度，设备切换后旧回调不能向新会话返还额度。

平台隧道和 SSH 分别在本地测试；尚未使用真实现场下位机完成三端联调，也未验证公网 TLS 部署、真实设备主机密钥、ARM64 及网络抖动。既有软件更新和独立 SSH 升级流程不作为本次远程隧道验收结果。
