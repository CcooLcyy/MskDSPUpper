# 协议页源端实时值查询方案

## 目标

ModbusRTU 和 DLT645 协议页面直接读取 DataCenter 保存的源端最新值。IEC104 根据站点角色选择缓存：MASTER 读取源端，SLAVE 读取路由后的目的端。

## 数据流程

协议模块采集点值后继续调用既有的 `DataCenter.Publish` 或 `BatchPublish`。DataCenter 在发布时更新进程内源端缓存，并保留原有路由转发逻辑。上位机协议页面按连接语义查询最新值：

- MASTER 及 ModbusRTU/DLT645：按源连接 ID 调用 `GetSourceLatest`。
- IEC104 SLAVE：按 IEC104 目的连接 ID 调用 `GetLatest`，获取外部源经路由转入从站的点值。

返回值均合并到点表中显示值、时间戳和质量。

## 接口语义

- `GetSourceLatest(conn_id, tags)` 查询指定源连接的最新值；`tags` 为空表示查询该连接缓存中的全部点。
- 返回的 `SourcePointUpdate` 使用 `conn_id/tag` 标识源点，不包含目的连接字段。
- `sequence` 仅在 DataCenter 当前进程内单调递增，用于诊断和消费方判断更新顺序；进程重启后重新计数。
- 源端缓存不落盘，连接删除时同步清理；协议模块重启后由下一次 `Publish` 恢复页面值。

## 上位机实现

Tauri DataCenter 客户端、命令和 TypeScript 适配器提供 `dcGetLatest` 与 `dcGetSourceLatest`。公共 Hook `useProtocolRealtime` 首次进入页面立即查询，之后以 500 ms 间隔轮询，并根据查询模式将目的端返回的 `dst_tag` 统一映射为页面 tag；请求异常只影响当前页面的错误状态，不会清空既有值。页面切换连接或点位时清空旧连接数据，避免跨连接串值。

### IEC104 无路由模拟值展示

IEC104 无路由模拟值不发布到 DataCenter。运行视图按点位 Tag 将当前模拟快照与 DataCenter 实时值合并：

- 当点位存在模拟值时，“实时值”和“时间”分别显示模拟值与模拟值生成时间，“质量”显示“模拟”。
- 当点位不存在模拟值时，值、时间和质量继续使用 DataCenter 实时值，保持原有展示逻辑。
- 生成模拟值后立即更新运行视图，不要求 IEC104 连接已启动；“应用并发送”只负责向已连接主站发送快照。
- 清除模拟值后立即恢复 DataCenter 实时值，不保留模拟标识。
- “模拟数据”面板中，FLOAT 遥测支持固定随机值和按 IOA 递增；SINGLE 遥信支持随机、全部为 `true`、全部为 `false` 和按当前值取反。遥信取反优先使用已有模拟快照，没有快照值时读取 DataCenter 最新值；缺少当前值时生成失败且不替换原快照。

## 边界条件

- 协议模块未调用 `Publish` 的点不会出现在源端缓存中；IEC104 SLAVE 还必须存在指向 IEC104 目的端的有向路由，否则 `GetLatest` 也不会有值。
- 死区过滤导致未发布的值不会更新缓存，这是现有协议模块发布语义，不在上位机侧补发。
- DataCenter 返回连接不存在或网络错误时，页面保留上一次成功值并显示错误状态。
- IEC104 模拟快照可以只覆盖部分点位；未匹配的点位仍显示 DataCenter 实时值。
- 只展示连接名与当前连接一致的模拟快照；模拟请求执行期间禁止切换连接，避免迟到响应造成跨连接串值。
