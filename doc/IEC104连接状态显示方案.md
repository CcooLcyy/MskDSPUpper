# IEC104 连接状态显示方案

## 需求

IEC104 连接列表左侧状态点用于表示链路功能是否已启动：只要链路状态为“运行中”，状态点就显示绿色；链路已停止、待删除或状态未知时显示非绿色。

TCP 会话是否已建立是独立的通信状态，继续通过连接列表描述文字和报文日志体现，不改变后端 `connection_state` 字段及其含义。

## 范围

- 配置视图和 SOE 视图中的 IEC104 连接列表统一按 `LinkInfo.state` 渲染状态点。
- 状态点悬浮提示与链路功能状态一致，避免将“运行中”链路误显示为 TCP 断开。
- 不修改 IEC104 协议、后端链路状态机、TCP 会话状态上报及其他协议页面。

## 验收标准

1. `state = LINK_STATE_RUNNING (2)` 时，IEC104 连接列表状态点为绿色。
2. `state` 为已停止、待删除或未知时，状态点不为绿色。
3. 页面源码不再使用 IEC104 `connection_state` 决定连接列表状态点颜色。
