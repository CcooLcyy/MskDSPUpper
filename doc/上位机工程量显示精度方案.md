# 上位机工程量显示精度方案

## 目标

上位机只调整工程量的只读展示：界面固定显示小数点后 2 位。下位机计算、协议字段、配置解析、配置保存和下发精度保持现状，Decimal 文本仍可携带 20 位及更高的有效小数位。

## 范围

- 数据总线、协议实时值、AGC 和 AVC 运行状态中的 Double/Decimal 工程量使用统一的两位小数展示规则。
- IEC104 模拟值表中的 Double 工程量改为两位小数。
- 只读配置摘要可以按两位小数显示；编辑控件的值、用于回填的 Decimal 原文、导入导出内容和控制命令继续使用原始十进制文本，不经过展示格式化工具。
- 布尔量、整数、字符串、字节数组、时间、百分比和资源容量等非工程量展示不作机械替换。

## 规则

1. Decimal 展示只接受字符串，采用字符串和 BigInt 计算，禁止先转 JavaScript `number`、`parseFloat` 或 `toFixed`。
2. 显示采用四舍五入（半数远离零），固定保留两位；例如 `1` 显示为 `1.00`，`-1.235` 显示为 `-1.24`。
3. 舍入为零的负数显示为 `0.00`，避免出现 `-0.00`。
4. 非法 Decimal 文本不改写，直接返回原文，避免展示层吞掉后端异常值。
5. 展示格式化只在渲染边界调用，不能改变状态对象、表单值或下发请求。

## 验收标准

- 公共展示工具覆盖整数、正负数、半数、20 位小数、科学计数法、负零和非法文本。
- DataBus、协议实时值、AGC、AVC 的 Decimal 实时值显示两位，Double 实时值也显示两位。
- 编辑/保存链路仍能保留 `0.12345678901234567890` 等完整原文。
- IEC104 模拟值显示两位，协议字段类型和编码不变。
- IEC104、Modbus RTU/TCP、DLT645 点表配置视图中的 Scale/Offset/Deadband（含 DLT645 数据块子项）显示两位小数，编辑控件仍保留原始 Decimal 文本。
