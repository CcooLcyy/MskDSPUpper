# IEC104 从站导入路由方向方案

## 目标

修正 IEC104 从数据总线导入点位时的 DataCenter 路由方向，使从站的遥控、遥调点作为命令源，遥信、遥测点作为数据目的端。

## 范围

- 仅适用于当前 IEC104 连接为从站的导入流程；主站导入方向暂不调整。
- 点表仍然按用户选择全部导入并保存。
- 勾选自动创建路由时，按导入点最终确认的 `business_type` 生成路由。

## 路由规则

| IEC104 点位业务类型 | 自动路由方向 |
| --- | --- |
| 遥信、遥测 | 数据总线来源点 -> 当前 IEC104 点 |
| 遥控、遥调 | 当前 IEC104 点 -> 数据总线来源点 |
| 参数、未分类 | 不自动创建路由 |

遥控和遥调的目标仍使用导入时选中的数据总线来源端点；遥信和遥测的目标使用当前 IEC104 连接及导入表格中最终确认的 Tag。

## 约束与异常

- 自动路由只接受遥信、遥测、遥控、遥调四类业务类型；参数和未分类点不阻止点表保存。
- 自动路由使用最终编辑后的目标 Tag，并保持源端模块、连接和 Tag 的稳定身份。
- 生成结果返回创建路由数量和跳过数量，页面提示跳过的参数/未分类点数量。
- 当前 IEC104 连接作为源端时仍禁止同连接自环。

## 验收标准

- 从站导入遥信/遥测生成 `来源 -> IEC104`。
- 从站导入遥控/遥调生成 `IEC104 -> 来源`。
- 参数/未分类只进入 IEC104 点表，不创建 DataCenter 路由。
- 未勾选自动路由时保持原有行为，不创建任何路由。
