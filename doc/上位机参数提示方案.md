# 上位机参数提示方案

## 目标

在配置表单的参数标签旁提供统一的 `?` 提示，说明专业术语、单位、取值语义及配置对通信或控制行为的影响，减少误配置和反复查阅协议文档的成本。

## 范围

第一阶段覆盖以下高风险配置：

- Modbus RTU/TCP：地址基准、功能码、数据类型、寄存器数、位索引、字序/字节序、串口参数、超时、轮询周期和工程量换算。
- DLT645：协议变体、表计地址、PCD 设备序号、DI、数据长度、位解析、读写属性、串口参数、超时和工程量换算。
- IEC104：传输/站点角色、CA/OA、端点、APCI 参数、ASDU 限制、时标/去重、IOA 及遥控参数。
- AGC/AVC：命令模式、控制方式、分配方式、控制周期、信号标签、单位、增量基准、成员权重/边界及电压控制参数。
- Modbus RTU、DLT645 的 MQTT 全局配置：Broker、客户端标识、保活、清理会话和连接超时。

普通名称、按钮和状态字段不默认增加提示，避免界面噪声。已有 `help` 校验信息和动态 `extra` 说明保持原用途不变。

## 实现约定

- 使用 Ant Design `Form.Item` 的 `tooltip` 属性，由组件统一渲染问号图标。
- 说明文案集中维护在 `src/components/help/parameter-help.ts`，按通用、协议和控制语义复用。
- Tooltip 最大宽度统一设为 360px，保证中文长说明可读。
- 文案中的公式和边界以对应 protobuf 注释及现有校验逻辑为准；如协议规则变化，需同步更新帮助常量和测试。

## 验收标准

1. 首批页面的高风险字段标签旁显示问号，悬停或点击可看到中文说明。
2. 说明至少包含字段用途，以及单位、默认值、边界或对运行行为的影响中的相关信息。
3. 校验错误、动态条件提示和表单提交行为不受影响。
4. 参数说明测试验证关键文案和页面接入数量。

## 后续工作
