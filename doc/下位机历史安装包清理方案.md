# 下位机历史安装包清理方案

## 目标与范围

用户已确认：下位机安装命令成功，且上位机确认 `mskdsp` 容器正在运行期望镜像后，自动删除设备上传目录中的本程序历史安装包，保留本次安装包。上传失败、安装失败、镜像不一致或镜像查询失败时不执行清理。上位机缓存与 Docker 镜像沿用既有规则。

## 执行流程

1. 成功安装后保存本次安装请求（包名、镜像 ID、目标账号、安装目录和认证信息），仅保存在页面内存中，重置安装状态时清空；重新确认镜像也使用这份请求，避免读取已切换的清单或目标。
2. 自动确认镜像、重新安装后确认镜像、手动重新确认镜像，共用“确认镜像 -> 清理历史包”的流程；没有成功安装请求则拒绝清理。仅预检发现目标已是最新而未下发包的路径不触发清理。
3. 确认失败或不一致时保留全部安装包。确认成功后调用新的 `cleanup_lower_update_packages` 命令，清理期间禁用重复下发操作。
4. 后端在执行删除前再次检查 `mskdsp` 容器确实正在运行，且镜像 ID 与请求一致。既有运行镜像查询在同一份内部结果中保存容器实际引用和清单所用的配置摘要；配置摘要确认一致后，删除脚本复核容器仍然运行这份结果的实际引用。这样可兼容 Docker 经典存储与 containerd 引用/配置摘要差异，也避免独立查询绑定到不同构建；任何条件不满足时不删除文件。实际引用仅是内部字段，不新增前端响应字段。
5. 清理成功展示删除数量与释放空间；清理失败记录中文日志并提示“升级已完成，历史安装包清理失败”，保留升级成功状态，允许通过重新确认镜像重试。

## 接口

`cleanup_lower_update_packages(request)` 复用安装请求字段：

- `package_name`：本次应保留的安装包文件名。
- `expected_image_id`：安装成功且已确认的镜像 ID。
- `upload_account`、`install_dir`、`auth`、`sudo_password`：本次安装使用的目标与认证信息。

成功返回 `{ remote_path, removed_files, reclaimed_bytes }`。SSH、提权、运行镜像确认或文件清理失败返回中文错误，前端只将其作为清理警告。复用现有 SSH 与 sudo 执行路径，设置超时；密码不得进入命令行、普通日志或落盘文件。

## 文件边界

- 仅枚举规范化安装目录的直接子项，不递归，不删除目录，不跟随符号链接；拒绝以根目录作为清理目录。
- 本次安装包必须存在、为普通文件且符合本程序安装包标识，否则停止清理，避免当前包缺失时删除剩余可重试包。
- 安装包名采用既有公开发布格式：`mskdsp-<版本信息>-linux-arm64` 或 `mskdsp-<版本信息>-linux-x64`，无扩展名；识别版本开头与允许字符，并核对自解压脚本的 `CONTAINER_NAME="mskdsp"` 和 `__ARCHIVE_BELOW__` 标识。
- 清理匹配上述规则的其他完整安装包，可跨通道和架构；始终排除当前包、`.uploading`、`.download`、debug symbols、镜像 tar、普通脚本、配置及其他业务文件。
- 逐段通过目录描述符打开安装路径，所有层级都拒绝符号链接，避免祖先目录链接将清理重定向到其他位置。
- 删除候选前，将其原子移入本次清理创建的私有隔离目录（权限 `0700`），再核对实际移入文件的类型与身份；匹配才删除，避免检查与删除之间同名文件被替换而误删。
- 身份不一致或删除失败时，不删除替换对象，以不覆盖原名的方式尝试恢复；无法恢复时保留隔离目录中的对象，返回中文错误与可恢复位置。只移除本次创建且已空的隔离目录，不递归清理。
- 重复清理是幂等操作，已无旧包时成功返回零。

## 测试与验收

先写失败测试，再实现：

1. 安装失败、镜像不一致、镜像查询失败：清理函数不被调用。
2. 安装成功且镜像匹配：确认先于清理，仅调用一次；清理失败仍返回镜像确认成功。
3. 普通部署、重新安装与手动重新确认镜像：使用成功安装的目标与包信息，均接入同一流程；浏览器与离线适配器完整接入新接口。
4. ARM64/x64、CI/beta/stable 包：旧包删除，当前包保留，返回正确数量和空间。
5. 无关文件、符号链接、目录、上传/下载临时文件、debug symbols、同前缀非安装包：全部保留，嵌套目录内容不变化。
6. 当前包缺失、不合法、为符号链接，目录为根目录，容器未运行或镜像不匹配：删除发生前拒绝。
7. 清理幂等；遇到删除权限或执行错误返回中文错误并记录日志。
8. 安装路径祖先为链接时拒绝；候选在移入隔离前被替换为无关文件时不删除替换对象，并安全恢复；恢复时不得覆盖其他并发创建的同名文件。
9. 原始容器引用与期望配置摘要不同，但既有运行镜像查询已验证配置摘要一致时允许清理；删除脚本仍检查原始引用，运行容器变化时拒绝。
