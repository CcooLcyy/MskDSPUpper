# 平台账号角色分配

第一阶段增加管理员（`admin`）、运维人员（`operator`）两种上位机账号角色，由平台 Web 管理员创建/编辑账号时分配。角色不授予平台 Web 管理权限，具体功能权限将在后续讨论后接入，本阶段现有功能可用范围及设备授权保持原行为。

登录及会话查询的 `AccountIdentity.role`（字段 4）携带平台当前角色；Rust 保存角色并向认证快照提供，账号入口显示中文角色。既有会话检查同步角色变化，不延长原会话、不重载草稿。角色只来自平台，不持久化到本地配置。旧平台空角色兼容为运维人员，未知非空角色拒绝。断网保留有效会话的最后角色，到期锁定，恢复连接后同步。

平台数据迁移、接口兼容、会话及验收要求见配套平台仓库 `docs/上位机账号角色分配方案.md`。本次仅本地验证，不更新已安装程序或部署平台。
