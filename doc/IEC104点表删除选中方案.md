# IEC104 点表删除选中方案

## 目标

在 IEC104 点表配置视图中支持勾选多个点位后一次删除，避免只能逐行删除或清空整张点表。

## 范围与交互

- 配置视图工具栏提供“删除点位”下拉按钮，菜单包含“删除全部点位”和“删除选中点位”两个选项。
- “删除选中点位”在未勾选点位、处于运行视图或存在其他进行中的操作时禁用；“删除全部点位”沿用原有点表范围限制。
- 选择删除范围后显示确认提示，并展示对应的点位数量。
- 删除范围按点位 Tag 计算，包含当前筛选条件下不可见但已保留勾选状态的点位。
- 保存成功后清空勾选；保存失败时保留勾选状态，便于重试。

## 保存语义

批量删除复用 `UpsertPointTable(replace=true)`，提交过滤后的完整点表。若链路正在运行，沿用现有停链、保存、恢复流程，不增加新的 gRPC 或 Tauri 接口。

## 测试验收

- 只删除勾选点位，未勾选点位保持不变。
- 删除入口在正确视图和勾选状态下启用，并要求二次确认。
- 保存成功后清空勾选，保存失败时保留现场。
