# IEC104 批量点位配置方案

## 目标

在 IEC104 上位机点表页面中支持粘贴多行点名，并根据起始 IOA 和步长一次生成连续点位，减少逐点配置的操作量。

## 范围

- 输入来源为文本框中的多行文本，每行一个点名；空行忽略。
- 首行点位使用用户输入的起始 IOA，后续点位按步长递增。
- 批量设置点类型、Scale、Offset、Deadband。
- 提交前在上位机预览并校验，不增加新的 gRPC 或 Tauri 接口。
- 保存时复用现有 IEC104 点表覆盖保存流程，以及链路停止/恢复保护。

## 约束与校验

- 点名首尾空白会被清理，空点名不生成点位。
- 点名不能与当前连接已有 Tag 或本次批量输入中的其他 Tag 重复。
- IOA 必须为 `1` 到 `0xFFFFFF` 的整数，且不能与当前点表或本次批量输入中的其他 IOA 重复。
- 步长必须为正整数。
- 点类型仅支持现有的 FLOAT（1）和 SINGLE（2）。SINGLE 点忽略工程量参数，并统一保存为 Scale=1、Offset=0、Deadband=0。
- 生成结果在确认提交前预览；通过文本框删除或修改点名，或调整批量参数后实时重新生成。提交按钮在存在校验错误时禁用。
- 预览表默认每页显示 100 个点位，可切换每页 50、100 或 200 条，避免大批量粘贴时一次渲染全部行。

## 保存语义

批量点位与现有点表合并后，以 `replace=true` 一次性保存完整点表。若链路正在运行，先停止链路，保存成功后尝试恢复；保存成功但恢复失败时明确提示用户。

## 测试验收

- 多行文本按行解析并忽略空行。
- 起始 IOA 与正整数步长生成连续地址。
- 正确报告重复 Tag、重复 IOA、非法 IOA、非法步长和空输入。
- SINGLE 点的工程量参数被统一为 Scale=1、Offset=0、Deadband=0。
- 合并后的点表仍通过现有点表保存入口下发。
