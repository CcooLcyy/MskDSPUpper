# 奥太与古瑞瓦特 Modbus 模板核对

本次将用户提供的两份原始 PDF 整理为离线内置 JSON 模板，原始 PDF 不复制到代码仓库。模板保留 PDF 文件名、SHA-256 和每个点位的来源页码；页码采用 PDF 实际页序，从 1 开始。

## 转换规则与验收

- 地址直接使用协议寄存器地址（0 基），不使用 4xxxx/3xxxx 参考编号；功能码保持与原表一致。
- 16 位量采用一个寄存器；原表明确 H/L 的 32 位量合并为一个点位，高字在前（HL）。寄存器内高字节在前（AB），依据原始请求/响应帧与标准 Modbus 数据格式。
- 工程量采用 `value = raw * scale + offset`。原表的 0.1V/0.1A/0.01Hz 等分辨率直接转换为倍率；缺失、矛盾、非线性编码不猜测。
- 型号分支必须拆分模板；选配、扩展路数点位标记 `default_selected: false` 和 `condition`，由用户确认后勾选。
- 写入点单列在“控制设置”组，默认不选；读取配置反馈采用 03，写命令采用 06。不能确认写入值域/编码的项排除。
- 核对要求：JSON 可解析，ID 唯一，地址不越界，类型与寄存器数一致，所有倍率可解析，型号范围符合文档；关键地址、倍率、端序结合页面渲染核对。

## 奥太

来源：`3_奥太逆变器规约点表.pdf`，18 页，SHA-256：`7115ecbc3eafe3347f7e99c44c02b57f81b30523ea482ed34d106d64e5cfa2dc`。

- 第 4 页：标准 Modbus RTU，03 读取，06 写单寄存器；9600/8N1 为设备说明，模板不覆盖连接参数。
- 第 5~6 页：小功率 HF/TL/TLD（小于 10kW）、中功率 TLC 10~30kW、大功率机型；红字与黑字分别描述中小功率和大功率，必须按颜色核对。
- 第 7~10 页：不同机型的交流电流、交流功率、直流电流与直流功率倍率不同，因此分别提供 HF/TL、TLD、TLC、ASP-30K/50K/100K、ASP-250K、ASP-500K、ASP-630K 模板。
- 第 9 页：22/23 为当天发电量；中小功率倍率 0.01kWh，大功率倍率 1kWh。24/25 为总发电量，所有机型倍率 1kWh，高 16 位在前。
- 第 10~13 页：第二路直流仅适用于 TLD 和 TLC；汇流箱 38~54 仅适用于带该功能且协议版本 1.5 的设备，默认不勾选。
- 第 15~18 页：故障位按型号列的勾选适用性收录；F3/F0/F1/F2 分别位于寄存器 4/5/6/7。

### 奥太排除与限制

- 18/30 无功量、0x2A 无功调整与 0x2C 无功反馈：存在正负值语义，但未定义负数的线上编码，不猜测 INT16。
- 26 温度：只说明正温度示例与倍率，没有有符号声明；避免负温度被错误解释，暂不提供该点。
- 27 功率因数：90~100 表示感性 0.90~1，100~110 表示容性 1~0.90，为分段编码，不能仅用线性 scale 处理，排除。
- 28 与 36/37 CO2 减排量：给出从累计电量推导公式，但没有清晰定义线上寄存器分辨率，排除。
- 第 7 页 ASP-30K/50K/100K 的功率示例写“5260×10=52.6kW”，算式有笔误；其文字“真实值乘以10发送”和最终数值 52.6 一致，采集倍率采用 0.1kW，并在模板说明中保留该问题。
- 小/中功率的保留寄存器（9、18、27、29、30）不收录；小功率单相机型不收录 B/C 相量。
- 没有真机证据证明负温度或负无功编码；模板完成静态协议核对不等于完成所有机型互操作测试。

## 古瑞瓦特

来源：`TH-275-00 古瑞瓦特逆变器外部通信协议V1.20 (6).pdf`，65 页，SHA-256：`f67b8fbf1b6925fa97e618ed58cc19daab098e9fcee6b13cbe70810c863fefdf`。

- 第 3 页明确型号范围：TL-X/MIN（03：0~124、3000~3124；04：3000~3249）；TL3-X/MAX/MID/MAC（03、04：0~249）；MIX/SPH（03、04：0~124、1000~1124）；SPA（03：0~124、1000~1124；04：1000~1124、2000~2124）。据此拆分四个模板，扩展 PV9~16 所在 875~999 不跨型号猜测收录。
- 第 5/9 页：保持寄存器和输入寄存器均声明 16 位无符号整数；仅针对明确“有符号”的字段覆盖类型。
- 第 5~7 页：功能码 03、04、06、16；模板读取采用 03/04，明确单寄存器控制项采用 06。
- 第 8 页：默认 9600/8N1；两次命令至少间隔 850ms，读取上限 125 个寄存器。模板不修改连接周期，应用前需核对实际连接设置。
- 第 9~32 页：保持寄存器与配置反馈；第 32~41 页：第一/第二输入组；第 44~48 页：储能输入组；第 50~51 页：SPA；第 52~61 页：TL-X/TL-XH 输入组。
- H/L 两行合并成 UINT32；第 41 页 232/233 明确实际输出无功功率有符号，合并为 INT32。第 5 页通用无符号声明用于其它明确数值字段，温度按该声明保留 UINT16，不另外猜测负温度编码。

### 古瑞瓦特排除与限制

- ASCII 字符串（固件、序列号、厂商、型号等）不受当前后端整数点位类型支持，排除。
- 电池低温设置 1009/1011 用 1000~1400 表示 -40~0℃，不是二进制补码/单一线性换算；功率因数 IPF 等 0~20000 编码不作为实际功率因数直接换算，排除。
- 表内允许负值但未明确 signed 编码的 PID 电流、组串电流、无功百分比、防逆流有符号限值等，排除，避免与第 5/9 页无符号声明冲突。
- 功率/能量名称与单位矛盾（04:116/117、230/231、236/237、1064/1065、2116/2117、3178~3181）不猜测正确单位，排除。其中 230/231 为视在功率却给 W；236/237 为无功电量却给 kWh；3178~3181 为能量名称却给 W。
- BMS 旧接口 1082~1123 要求另一份 ESS Protocol，且多数缺失量纲与分辨率；不以同名 TL-X 新接口的倍率套用，排除。
- 1124/1125 高低字跨越第 3 页给出的 1000~1124 范围，1126 以后与 875~999 扩展组没有明确型号范围确认，暂不收录。
- 调试数据、保留字段、刷新固件、恢复出厂设置等维护命令不作为常用点表预置；不支持字段与矛盾项列表将在完成整理后附录统计。
- 路数、三相、BDC、UPS、PID 与组串等功能取决于实际机型和选配；相关点位默认不选，并显示条件。

## 追加核对说明

- 古瑞瓦特 04:112~115：第 36 页 MAX 和储能共享地址但语义不同。TL3-X 使用 MAX 警告/功率百分比/故障字段；MIX/SPH 使用 112/113 当天 AC 充电电量与 114/115 总 AC 充电电量，均为 UINT32、倍率 0.1kWh。114 在 MAX 分支缺失时间单位，暂不收录。
- 古瑞瓦特 04:125~140 的奇数寄存器为 PID 电压；偶数寄存器为负范围 PID 电流，因未定义负数线上编码排除。04:143~173 的奇数寄存器均为负范围组串电流，全部排除，保留相应电压与状态字。
- 古瑞瓦特 03:04 无功百分比、03:123 防逆流有符号限值与 03:137/138 无功设置值没有足够负数编码依据；不直接当作有符号数配置。03:05、111/113/115/117 的功率因数配置为编码值，未提供完整可线性转换规则，不收录。
- 古瑞瓦特 03:42 同地址有多机防逆流主机失效和 G100 fail safe 两种定义，缺少型号区分，排除。
- 古瑞瓦特 03:1009/1011/3031/3033 低温分段编码排除；03:174 名为二阶高压穿越时间，但单位为 0.001Un，排除；03:92 “10times”与值域不够清晰，排除；03:162/176/178/179 缺失明确量纲或分辨率，排除。
- 古瑞瓦特 04:3017/3018 的 PV4 功率只写“0.1”而没有 W 单位，排除；其它 PV4 电压/电流可选。04:3100、3161 等功率因数编码无完整转换规则，排除。
- 古瑞瓦特 04:1082~1123 的旧 BMS 字段因引用另一个 ESS 协议而排除；TL-X 04:3212~3229 有明确本表分辨率，按本表单独收录并默认不选。
- 古瑞瓦特第 5 页响应例直接列出每个寄存器的 Data Hi 在 Data Lo 之前，因此 AB 有原表依据；所有 H/L 双字按相邻高位/低位寄存器合并，HL 有原表依据。
- 古瑞瓦特 TL-XH 来自第 52 页标题“用于 TL-X 和 TL-XH”，第 3 页未单列其完整型号范围；扩展点位默认不选，模板备注要求确认实际设备支持。
- 静态检查覆盖全部 11 个模板的可解析性、ID/标签唯一、寄存器数量、地址范围、倍率、页码、来源哈希和默认选择属性；关键页已渲染核对。未完成真实设备联调。
