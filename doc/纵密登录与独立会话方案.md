# 纵密登录与独立会话

## 目标与范围

用户于 2026-10-24 确认登录设计。纵密上位机指 NSS3000 配套配置软件，上位机指 MskDSPUpper，下位机指 DSP 中运行的程序。

在纵密访问工作台中接入独立登录：继承当前直连／平台远程路径和目标 11.22.33.44，角色为系统管理员、安全操作员、日志审计员。纵密身份不复用平台、上位机或 SSH 身份。连接检查不作为账号认证成功的依据，ICMP 不响应不禁止尝试管理连接。

本轮不改 DSP 网络、平台协议或远程 IP 通道，不自动连接真机、登录、改密或下发配置。现有访问和网络配置改动仍在工作区。

用户确认有真机可用于后续联调，但目前尚需先打通电脑经 101／108 到纵密目标的访问路径；提供的系统管理员凭据仅用于届时的授权联调，不进入仓库和测试。不能把已有 DSP SSH 设备可达当作纵密 TLS 服务已经可达。

## 证据与实现边界

依据相邻 `纵密上位机解析/analysis/full-restoration/source/netkeeperui` 的 LoginJPanel、MyMDI 和 net/ClientSocket，以及 login-analysis 文档。正常入口使用 TLS/TCP 8888；当前副本 nuc980=1 时三种角色使用 SM3(用户名+密码) 大写十六进制摘要。旧模式 PIN 分支留待设备版本确认，不静默套用。

连接证书首次配置后在当前进程复用；口令和原始登录秘密不写入普通设置、浏览器存储或日志。后端加载用户选择的客户端 PKCS12 与信任证书，不能从逆向工程复制私钥到仓库。界面明确证书格式和当前进程有效范围。证书校验失败禁止明文回退或跳过验证。

初版接受 PKCS12 客户端证书和 PEM／DER 信任证书；原软件 JKS 信任库需要事先转换。本轮不内置 JKS 解密或自动提取原软件证书口令。目标 TCP 地址始终固定；证书中的装置名称仅用于 TLS 身份校验，不改变实际连接目标。

2026-10-26 的完整抓包经离线解密并校验，已确认本次装置普通登录应答返回字段为 17、过期标志为 0。当前仅接入该字段及完整合法资料结构；未知应答仍返回未验证并关闭连接，不把所有非零返回值解释为成功。设备返回的锁定、UKey、许可、过期状态分别处理。默认密码在登录应答通过后由客户端独立检查。实现范围与验收见 [纵密默认密码修改与重新登录](纵密默认密码修改与重新登录.md)。

## 页面与状态

2026-10-28 用户确认：登录角色默认选择“系统管理员”（role=1），保留安全操作员、日志审计员切换；账号和密码仍由用户手动输入，登录请求使用当前选中的角色，认证与账号角色校验保持不变。本轮不调整登录后的业务界面。验收检查初始角色、手动登录请求的角色值及原有角色切换行为。

登录位于侧栏“纵密 → 登录”的独立页面 `/security-login`；访问通路与网络检查位于 `/security-access`，业务网络配置仍位于 `/security-config`，三项由同一“纵密”菜单展开。登录卡片展示当前访问路径、固定目标、角色、用户名、密码，连接证书配置默认收起。进度区分连接、TLS、身份认证与读取资料，由后端结果驱动，不使用定时器伪造成功。页面组织及路由验收见 [纵密导航与登录页面拆分](纵密导航与登录页面拆分.md)。

认证中锁定目标和角色，支持取消。取消、切换目标、卸载及迟到结果均清理对应请求；返回会话必须在展示前通过结果约束检查。证书口令、密码在提交后清空；切换角色、取消或离开页面同步清空。登录失败后由用户手动重试，不重复提交凭据。

密码过期／默认密码处理单独呈现；修改能力未验证时明确不可用，不能显示假成功。修改成功也应重新登录。断线、失败、取消均清空纵密身份，不能关闭整个上位机。当前阶段未开放的业务入口使用明确待接入状态，不执行维护或写入命令。

## 接口

能力查询：`getVerticalSecurityLoginCapabilities()`。

证书配置：`getVerticalSecurityCertificateProfile()`、`configureVerticalSecurityCertificateProfile(request)`。只返回路径与配置状态，不返回证书口令、私钥或证书正文。

认证：`loginVerticalSecurity(request)`，输入请求标识、路径、目标设备标识（远程时）、角色、用户名和密码。固定服务端目标，不接收任意端口、命令或可执行脚本。

取消：`cancelVerticalSecurityLogin(requestId)`；退出：`logoutVerticalSecurity(sessionId)`；密码修改：`changeVerticalSecurityPassword(request)`。尚无真实资源时不得声称已经建立或关闭会话。

前后端类型以 `src/adapters/types.ts` 为统一界面契约，Rust 采用对应 snake_case 字段。

## 验收

- 后端 fixture 验证登录编码、SM3 标准向量、分片读取、锁定／UKey／许可／过期／未知应答及长度边界。
- 页面真实组件配合虚构 IPC 验证成功与异常、取消后迟到结果清理、角色和目标隔离、口令清空、证书缺失和远程不可用。
- 浏览器预览不得模拟真实登录成功；仅专用测试 fixture 提供虚构结果。
- 前端构建、静态检查及相关离线／工作流测试；后端定向测试。真机结果与源代码、fixture 结果分开记录。

## 当前实现与验证结果
