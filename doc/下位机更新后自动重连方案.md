# 下位机更新后自动重连

## 目标与边界

下位机更新成功后，上位机自动重新建立业务连接、获取运行模块地址，并刷新正在显示的模块运维和系统总览。用户无需再进入模块运维点击“连接”或“刷新”。不修改下位机接口，不自动启动模块或模块内功能。

## 输入与执行顺序

- 使用更新任务固定的 SSH 账号地址或平台入口与设备编号识别目标；重连不需要 SSH 或 sudo 密码。
- 直连安装及运行镜像确认成功、历史包清理结束后执行重连；清理失败仍执行重连。
- 平台远程更新确认原任务成功后执行重连，包括重新打开上位机后恢复查询成功的任务。
- 已是目标版本时也刷新连接。安装失败、镜像不一致、任务结果未知时不按更新成功处理。
- 仅刷新当前业务连接对应的更新目标；当前已连接其他设备时跳过，不自动切换设备、地址、平台或账号。
- 使用当前目标的独立连接重新查询 ModuleManager 运行信息与模块清单，成功后一次替换旧业务连接和模块地址缓存，模块端口变化时使用新的地址。失败不破坏当前缓存；异步期间连接切换时，旧响应不得覆盖新目标的地址缓存。平台远程连接保留当前 SSH 会话。
- 服务尚未就绪时有界重试，最多六次，每次间隔三秒，单次后端操作有超时；只重试读取和重连，不重试安装。

## 状态与异常

镜像确认后的“恢复业务连接”阶段仍占用更新任务，完成后统一显示结果。页面切换不取消重连。重连成功通知正在显示的模块运维和系统总览重新读取数据。重连失败在更新成功结果中单独警告，不改判成更新失败；结果窗口可单独重试连接，避免重新上传或安装。日志记录重连开始、成功、跳过及失败，不包含密码。

## 验收

- 直连和远程更新成功均自动重连；完成状态必须在重连结束后显示。
- 旧模块地址缓存清除，新运行信息写入；当前页面接收刷新通知。
- 清理失败不妨碍重连；暂时失败后自动重试；重试耗尽保留更新成功与连接警告。
- 已是目标版本、远程原任务恢复查询成功也执行重连。
- 安装失败、镜像不一致、未知结果不触发成功重连；更新另一设备或重连期间切换设备不得覆盖当前连接。
- 单独重试连接不再执行上传、安装、镜像查询和旧包清理。
- 使用控制器测试、连接目标匹配及代次测试验证，执行前端构建和相关检查；真机升级恢复另作联调验证。
