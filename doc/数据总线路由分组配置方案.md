# 数据总线路由分组配置

## 目标和边界

已确认将批量新增路由改为多组连接映射，在一个弹窗内配置多组后统一创建。仅修改上位机交互，不改变下位机接口、数据转发语义或离线工作区格式。

## 交互与数据

- 每组独立保存源连接、目标连接、一对一选择顺序、自定义映射和当前编辑模式，切换组不清空草稿。允许新增任意多组；组标题显示连接名称与完整映射条数。
- 更换连接只影响本侧选择。已有受影响点位时，提供取消、更换并清空本侧、保留当前组并新建三种操作；另一侧的点位和自定义映射字段保留。同一连接不触发清空。
- 点位可搜索、追加选择筛选结果。按同名标签匹配须先展示结果，再由用户采用；不会自动下发。匹配按完整标签精确相等，按源目录顺序配对。
- 已选点支持拖动排序；配对表显示序号、源点、目标点和校验结果，可移除配对。自定义映射仍支持一对多、多对一，并说明多对一是后到值覆盖而非计算汇总。
- 一对一与自定义模式的草稿均保留且计入提交预览。未完成映射不静默丢弃，延续原有确认后仅提交完整配对的行为。
- 各组共同检查重复、已存在路由、反向冲突和自环。重复项只创建一次，反向冲突、自环阻止提交。预览显示所属组并可定位。
- 删除有点位的组、关闭有草稿的弹窗需确认；提交期间禁止再次提交、编辑和关闭。失败保留所有草稿，成功后关闭并刷新路由列表。
- 页面“拓扑配置”更名为“路由配置”。

## 验收

1. 连续新增至少三组，来回切换后各组选点及顺序完整保留，统一提交包含全部组。
2. 分别更换源/目标连接，取消保持草稿；确认只清空本侧；选择新建时旧组不变、新组继承未更换侧的选择。
3. 自定义映射更换任意连接时另一侧字段保留；重复选择相同连接不损失数据。
4. 搜索选择保留原有选择和顺序，同名匹配预览与采用结果一致，无同名点时不覆盖草稿。
5. 跨组重复去重、反向冲突和自环阻止提交；组预览可定位，失败后草稿可继续编辑。
6. 关闭、删除和提交中的保护生效；已有路由及控制编排内部路由的管理边界不变。

## 验证方式

先补草稿逻辑行为测试并记录未实现时的失败，再实现；执行相关 workflow/offline 回归、lint、前端构建，使用本地浏览器样例核对关键交互。仅验证本地上位机，不代表设备转发联调。
