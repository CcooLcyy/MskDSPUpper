# 平台账号登录与启动门禁

## 目标与边界

上位机启动后先显示平台登录界面，平台普通账号验证成功后才能读取业务设置、挂载配置工作台和执行配置操作。没有跳过登录或匿名离线配置入口。平台管理员在 Web 创建普通账号，普通账号没有平台 Web 管理权限。本次不实现远程控制，也不按不同账号细分功能权限。

上位机与平台所有交互统一使用 gRPC。登录、会话查询、退出和 Agent 双向长连接均使用同一个平台地址；已有软件目录与安装包传输继续使用 gRPC。HTTP 仅由浏览器 Web 管理使用，上位机不调用平台 HTTP 登录接口，也不设置 HTTP 回退。

## 登录窗口

程序以 820 × 560 的居中横向窗口启动，左侧产品信息、右侧登录表单铺满窗口内容区，不保留外围背景或留白；紧凑间距为提示信息和登录操作预留空间，展开设置或信息较长时允许滚动，窄屏改为上下布局。首次成功进入配置工作台时展开到 1440 × 900，并限制在当前屏幕工作区内；用户已最大化时保留最大化状态。后续退出、过期锁定和同账号重新登录不重复缩放，保留工作时手动调整的窗口大小。窗口调整失败不影响登录，可手动调整。

## 登录与有效期

启动时不信任磁盘中的任何“已登录”标记。默认要求输入用户名和密码；可选择自动登录，但每次新进程仍必须向平台重新验证，验证成功前只显示登录/验证进度。

登录成功后，Rust 内存保存访问令牌和平台返回的本次会话截止时间；前端只收到账号、连接状态和截止时间，不收到令牌或保存密码。配置操作与登录租约绑定：网络临时断开时，本次已验证且未过期的会话仍可本地配置，平台操作暂停并以退避方式重连；断网或重新查询不能延长原截止时间。平台明确返回未认证、禁止访问或账号停用时立即撤销本地资格；网络超时和服务暂不可用不等同于账号被撤销，但到期仍必须锁定。

到期、被撤销或退出后展示登录界面，停止新的配置命令。此前已经提交给设备的操作不自动回滚。已打开的配置视图在内存中隐藏并禁用，供同账号重新登录后恢复草稿；不为锁屏把配置或密码写入浏览器存储。保留草稿时不允许直接切换为另一账号，以免暴露旧账号的内存草稿；需要切换账号时先保存并重启程序。主动退出前提示保存修改。

## 连接与凭据

- 平台连接设置只包含 gRPC 地址，默认沿用现有软件下载平台地址，可在登录前调整。
- 用户名、地址、记住密码与自动登录选项及程序自动生成的安装实例标识保存在运行数据目录的 `platform-login.json`；不保存密码或访问令牌。旧版已启用自动登录的设置自动兼容为同时记住密码。
- “记住密码”和“下次自动登录”独立显示；自动登录必须同时记住密码，取消自动登录仍可保留密码。取消记住密码同时关闭自动登录，并清除对应凭据；变更平台或账号也清理旧凭据。密码通过 Windows 凭据管理器按平台与账号隔离保存，仅登录验证成功后更新保存内容；凭据保存失败明确提示，不伪装成已记住。
- 登录页仅查询当前平台账号是否存在已保存密码，不将密码返回前端。存在凭据时提示“已记住密码，留空即可登录”，用户可输入新密码覆盖；凭据缺失、读取失败或认证失败时允许手动重新输入。使用已保存密码也必须向平台重新认证，不能恢复旧令牌或跳过门禁。
- 工作台锁定或主动退出后不自动提交密码；保留记住密码选项时，用户点击“登录”才使用已保存密码。取消记住密码的设置保存失败时提示错误并保留可见的原设置，避免界面误报已清除。
- 登录失败、退出、失效和页面离开均清除前端密码输入，不在日志中输出密码、令牌或完整请求/响应。
- 一个进程只保留一组当前账号会话。重复点击、旧网络响应、退出和新登录之间使用代次/取消机制，旧结果不得恢复已撤销的资格。
- Agent 连接发送自动安装实例标识和程序版本，定期心跳；断线使用原会话重连，不反复提交密码。退出取消后台连接和重试，尽力调用平台 Logout；平台不可达时本地退出仍立即生效。
- HTTPS gRPC 使用正常证书和系统信任根，不忽略 TLS 校验。既有明确配置的 HTTP gRPC 地址继续兼容，本次不变更服务器部署。

## 前后端接口

Tauri 提供匿名可调用的登录命令：`get_platform_login_settings`、`save_platform_login_settings`、`has_platform_saved_password`、`platform_login`、`platform_auto_login`、`get_platform_auth_status`、`platform_logout`。`has_platform_saved_password` 只返回当前平台与所填账号是否有已保存凭据；`platform_login` 接收独立的记住密码与自动登录选项，留空密码时仅在已记住的同账号下读取系统凭据。

其余应用自定义命令在统一分发入口调用 Rust 登录检查；未登录、过期或已撤销时直接拒绝，不能靠手工调用配置命令绕过登录界面。前端工作区模式与平台登录是独立状态，离线工作区同样需要有效登录。首次读取/迁移业务设置从 `main.tsx` 的匿名启动阶段移动到认证后的初始化阶段。

平台 AgentService 新增 `Login(LoginRequest)`、`GetSession(SessionRequest)`、`Logout(SessionRequest)` 三个 RPC，复用平台已有账号与会话服务。`GetSession`/`Logout` 与 `ConnectAgent` 使用唯一 `authorization: Bearer ...` metadata；`GetSession` 不回显访问令牌。实例协议在上位机独立生成，不修改已有软件协议子模块；两端的 Agent 协议保持一致。

## 验收

先补状态机、存储和真实随机端口 gRPC 测试，再实现。验证首次启动无配置闪现、自动登录只尝试一次、认证失败无法配置、普通账号成功登录、令牌不进入前端、断网租约不延长、到期/撤销/退出锁定、同账号草稿恢复、并发及旧响应不会重新解锁，以及设置与凭据中没有明文秘密。

统一门禁使用 Tauri mock IPC 验证真实分发：匿名配置/工作区命令不会执行，只有登录命令可以访问；有效资格允许执行，撤销后再次拒绝。运行前端 workflow/offline 测试、构建与 lint，以及本地可用的 Rust 测试。平台侧独立验证新增 RPC 与原账号/会话共享，登录后接入、改密/禁用/退出后断开。不自动部署或进行设备操作；本地模拟客户端验证不代表现场联调。

记住密码验收覆盖：仅记住但不自动登录、旧设置迁移、自动登录联动记住、取消自动登录保留凭据、取消记住清除凭据、账号和平台隔离、缺失或错误凭据不授予资格、锁定和退出后需手动点击登录、输入新密码覆盖旧凭据、并发设置变更不能恢复旧会话。测试使用模拟凭据存储与本地随机端口平台，不代表已验证 Windows 凭据管理器的真实交互。
