# AGC 成员外部闭锁配置

每个可控成员可独立选择「禁止增出力遥信（可选）」和「禁止减出力遥信（可选）」。默认均不绑定；仅测量成员不配置闭锁。可从已有协议点表选择产生 BOOL 值的点位，AGC 直接读原始布尔值，不使用单位或工程量换算。组默认闭锁遥信仍是独立的只读输出。

确认成员只更新组草稿。保存控制组时提交成员配置，以各自独立的组内标签建立从协议点到 AGC 的入向路由。重开成员应读回原绑定；清除一路只移除该路配置和路由，切换成仅测量成员则清除两路。新建或换绑使用新标签，避免把旧路由的最后值当成新来源的输入。老配置没有这两个字段时继续按原行为运行。上位机与下位机均需采用包含新协议的构建。

已绑定的遥信置位只限制相应方向，其他成员分担剩余目标；解除后使用当前总目标重新分配。用例 37 保持原场景和断言，业务代码通过各项目 CI 验证，现场执行另行确认。
