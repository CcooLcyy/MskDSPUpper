# 协议连接运行中删除方案

## 目标与范围

Modbus RTU、Modbus TCP、DLT645 与 IEC104、IEC61850 保持一致：允许删除运行中的连接，由下位机删除接口先停止连接功能，再清理资源与配置。本次只调整这三个上位机页面，不改下位机接口。

## 交互与异常

- 所有删除均保留二次确认；运行中明确提示“连接正在运行，确认停止并删除连接 <名称>？”，停止态沿用普通删除提示。
- 确认后直接调用对应 DeleteLink，不额外调用 StopLink，也不恢复运行。
- 删除期间沿用现有操作禁用逻辑，避免重复提交。
- 仅删除接口成功后清除当前选择并刷新列表；失败显示错误、刷新实际状态，不提前移除连接或提示成功。
- 下位机停止失败或清理失败（包括待删除状态）均按接口错误处理，保留现场，不自动重试。
- 离线工作区沿用其删除配置行为，不操作设备。

## 验收

- 三类协议运行态、停止态均提交一次 DeleteLink；请求未完成时保留当前选择。
- 删除失败保留选择、显示错误并刷新；已有复制或删除操作进行时不再提交。
- 运行态确认框说明停止与删除，停止态保留普通提示。
- 通过对应流程测试、前端类型与构建检查。
