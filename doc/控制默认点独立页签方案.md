# 控制默认点独立页签方案

## 目标

在控制页面顶部将“默认点”从控制策略详情中提取为独立页签，页签顺序统一为：

`控制策略 → 默认点 → 控制日志`

AGC 与 AVC 使用相同的导航和交互约定，但始终读取各自模块的控制组及默认点数据。

## 页面行为

- `控制策略`继续展示控制组配置、运行状态和成员配置；不再重复展示默认点表格。
- `默认点`展示当前模块的控制组列表，选择控制组后在右侧查看该组默认点、数据方向、最新值和说明。
- `控制日志`保持现有占位内容不变。
- 默认点页签打开时继续轮询选中控制组的实时值，确保“最新值”与策略页一致。
- 默认视图仍为 `strategy`，已有链接和书签保持兼容。

## 验收标准

1. AGC 和 AVC 顶部均出现“默认点”页签，位置在“控制策略”和“控制日志”之间。
2. AGC 默认点页只显示 AGC 控制组数据，AVC 默认点页只显示 AVC 控制组数据。
3. 切换到默认点页后可以选择控制组并看到该组默认点表格；无控制组或无默认点时显示明确空状态。
4. 策略页不再渲染默认点卡片，日志页行为不受影响。
