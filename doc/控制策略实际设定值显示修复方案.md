# 控制策略实际设定值显示修复方案

## 问题

AGC、AVC 控制策略页面当前只通过 DataCenter `GetLatest` 查询运行值。该接口返回目的端缓存：外部设备经路由进入控制组的测量值可以正常显示，但控制模块自身发布的成员设定值、总目标、偏差和默认输出点属于源端缓存，因此页面显示为 `—`。

## 方案

AGC、AVC 运行监视同时查询同一控制组连接的两类最新值：

- `GetLatest`：读取目的端缓存，保留输入测量值的现有展示路径。
- `GetSourceLatest`：读取控制模块源端缓存，补充成员设定值、派生输出和默认点。

前端将源端更新归一化为现有运行值结构，并按 tag 合并。源端值优先，避免同名目的端缓存覆盖控制模块刚发布的实际设定值。DataCenter 的接口语义和下位机控制计算无需修改。

## 验收标准

1. AGC、AVC 的成员测量值仍显示目的端最新值。
2. AGC、AVC 的成员实际设定值在没有输出回路路由时也能显示源端最新值。
3. 两页的总目标、偏差和默认点最新值使用控制模块源端值。
4. 任一页面刷新失败时，沿用现有错误提示和运行状态处理。
