# 下位机更新后台执行方案

## 目标与范围

下发安装开始后，收起进度窗或切换页面不影响上传、安装、运行镜像确认和历史安装包清理。应用顶栏提供全局任务入口；任务结束后，在当前页面弹出一次结果提示，不自动跳转页面。

本次不增加取消、回滚、退出上位机后继续执行或重启恢复任务能力，不修改下位机安装脚本或 SSH 后台接口。

## 任务生命周期

- 任务编排和状态放在路由外的应用级管理层，页面仅提交任务和展示状态。
- 全局同一时刻只允许一个下发安装任务，启动时同步占用任务位置，避免双击和异步预检期间重复启动。
- 任务启动时复制安装包清单、本地文件、连接参数和密码保存选项。后续页面表单、通道或架构的变化不改变任务目标。
- 顺序为下发前目标镜像预检、上传、安装、运行镜像确认、历史包清理。目标已运行指定构建时跳过重复上传和安装。
- 镜像不一致或无法确认时保留所有历史包；清理失败不改变已经确认的升级成功结果。
- 保留重试流程、重新上传并安装、重新安装、重新确认镜像入口，均使用该任务的固定目标和安装包。
- 凭据只用于内存中的任务执行和现有明确选择的凭据保存流程，不写入任务展示快照或日志；仍遵守凭据撤销协调规则。

## 界面行为

- 进度窗的“后台执行”和右上角关闭均只收起窗口，任务继续执行。
- 顶栏在任务存在时显示阶段，点击重新打开详情；回到软件更新页面可查看同一任务。
- 完成弹窗区分更新完成、已是最新、更新完成但历史包清理失败、预检/上传/安装失败、镜像不一致/确认失败。
- 每次执行或显式重试的结果只自动提示一次。查看详情会收起结果提示，避免窗口叠加；关闭提示不删除任务记录。
- 安装日志、运行镜像与清理结果均可在全局详情查看。任务运行时可正常浏览其他页面。

## 异常与验收

- 上传过程中卸载页面订阅后，安装、确认和清理仍按顺序执行。
- 安装与镜像确认期间切页不丢失进度，返回页面或点击顶栏仍查看原任务。
- 启动后修改输入对象不能改变后续上传、安装和清理的目标。
- 重复启动被拒绝；失败不会执行后续危险步骤；清理失败明确提示且可重新确认后重试。
- 收起详情后终态提示在任意路由可见，每次终态提示可关闭且不重复出现。
- 保留现有通道/架构/包一致性和已是最新跳过安装的检查。
- 执行任务编排测试、相关回归测试、TypeScript 构建与 lint；不自动连接或更新真实设备。

## 验证结果

- 新增 16 项任务行为测试，涵盖切页继续、参数快照、重复启动、失败停止、镜像确认、清理重试、凭据撤销及进度过滤。
- `npm run test:workflow`：422 项全部通过；`npm run test:offline`：74 项全部通过。
- `npm run lint`、`npm run build` 与 `git diff --check` 通过；构建保留现有的大分包提示。
- 浏览器通过本机测试清单与模拟适配器验证完整下发流程：安装中切换到数值计算页，任务继续确认与清理，并在数值计算页显示结果弹窗。
- 关闭结果提示后，从顶栏可重新打开详情；返回更新页仍展示原任务及当前运行镜像，不重复弹出已关闭的结果。
- 同一目标与构建的任务结果用于更新页构建信息；切换目标或版本后不混用其他任务的镜像与状态。
- 未连接真实下位机，未执行真实 SSH 上传、安装、容器替换或远端清理。
