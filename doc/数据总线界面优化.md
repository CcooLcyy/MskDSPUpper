# 数据总线界面优化

## 范围与交互

保留现有连接目录与路由表布局、批量映射弹窗和路由接口，仅优化配置页的可读性与操作入口。

- 连接目录与标签目录各自搜索、滚动，连接名称支持换行；标签完整显示并支持复制，移除重复的“自动同步”列。
- 左侧可拖动调宽，也可收起后从路由工具栏重新展开；收起不清空搜索与当前连接。
- 选中连接可“以此连接为源新增”，点位行可直接以该点为源打开原有弹窗；只预填草稿，仍须选择目标并确认创建。
- 无路由时展示说明与直接新增按钮，隐藏无意义的筛选和删除操作；筛选无结果时保留筛选栏并提供清空入口。
- 选中路由后展示选中数量及删除按钮，“全部删除”移入更多菜单；删除继续使用原有确认与内部路由保护。
- 状态列明确为“配置状态”；配置存在不代表数据正在转发。具备实时能力时提供运行监视入口。
- 离线工作区通过已有能力上下文显示当前工作区名称与“仅修改本地工作区，不会自动下发到设备”的提示，不改动全局工作区流程。

## 验收

1. 普通与窄窗口中连接列表、标签目录及新增入口均可访问；长标签不会被不可恢复地截断。
2. 搜索连接和标签互不干扰；无结果时能清空搜索。收起再展开保留当前选择。
3. 连接或点位快捷新增正确带入源端；取消不创建路由，原有映射规则与冲突保护继续生效。
4. 首次空状态、筛选无结果、已有路由和多选状态各有明确操作；批量删除保留确认。
5. 执行数据总线相关回归、离线能力回归、lint 与前端构建；浏览器样例核对布局和交互。浏览器样例不代表真机转发验证。
