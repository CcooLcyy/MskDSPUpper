# 纵密访问与网络配置工作台

## 已确认范围（2026-10-24）

- 将“纵密访问”和“纵密网络配置”作为两个独立侧栏页面，只通过侧栏切换。
- 访问页使用已确认的连接工作台布局：左侧连接和分阶段结果，右侧访问路径。
- 保留 101 口直连；目标为 `11.22.33.44`，纵密侧出口为 DSP 108 口。不增加管理协议、端口或网页访问限制。
- 平台远程展示可访问的 DSP 及设备标识；不得切换其他业务页面的全局目标设备。
- 平台出口由 DSP 路由决定，可能是 PPP 或外置以太网 4G 路由器，不增加出口选择。
- 用户明确要求虚拟网卡和远程 IP 通道留待后续指导。本轮不安装驱动、不实现 IP 隧道、不变更下位机或平台协议，也不执行设备脚本或部署。

## 本轮行为

### 纵密访问

直连检查仅执行 Windows 本机网络查询及到固定目标的有界 ICMP 检查，不写入地址、路由或 NAT。依次展示电脑网络、目标路由和往返响应。ICMP 成功只代表本次检查得到响应，不代表所有协议、端口或专用配置软件均已联调；ICMP 无响应也不能独立证明业务通信不可用。

平台远程可选择平台设备和查看访问路径，明确展示“远程网络通道待接入”。在真实 IP 通道接入前不得出现“已连接”或可使用的本机端口映射。平台在线、SSH 可达不视为纵密网络访问成功。

页面提供请求代次保护，切换模式、目标或离开页面后忽略旧检查结果；检查期间锁定模式和设备。复制操作仅复制目标 IP。

### 纵密网络配置

复用原有脚本生成、SSH 上传、systemd 安装和状态查询。此次不改变设备脚本的网络行为，也不自动执行。配置页保留 SSH 直连，避免把尚未适配的平台部署选项展示为可用。

表单按本端／对端业务地址分栏；连接认证与部署目录收起。取消内置密码。对端网关明确提示当前脚本仅保存该字段。应用前预览脚本及持久化服务变更，原有分步执行结果继续保留。

## 接口契约

- `getVerticalSecurityAccessCapabilities()`：返回 `remote_ip_available` 和 `remote_ip_reason`。本轮真实后端返回不可用；浏览器预览不得模拟远程成功。
- `checkVerticalSecurityAccess({mode, device_id?})`：固定访问目标，不接受任意主机、端口或命令。返回 `mode`、`target_ip`、`device_id`、`state`、`session_id` 和分阶段 `steps`。
- `state` 为 `ready | failed | unsupported`；步骤状态为 `success | failed | unsupported`。直连无持久会话，`session_id` 为 null。
- `closeVerticalSecurityAccess(sessionId)`：保留未来通道清理契约；本轮不创建通道，非空未知会话应报错，不能声称已清理不存在的系统资源。

## 异常与验收

- 非维护网段、使用保留地址、不可用接口或目标路由选错接口时返回明确失败，不运行写网络配置的命令。
- 网络查询、ICMP 和子进程均有超时；非 Windows 环境明确不支持，不伪造成功。
- 测试使用网络快照和探测结果 fixture，不连接真实设备。
- 前端覆盖双页面导航、无协议／端口输入、无重复跳转入口、远程待接入状态、检查取消与旧结果保护。
- 运行相关前后端测试、构建、静态检查及浏览器交互检查。未运行真机／远程联调时单独报告限制。
