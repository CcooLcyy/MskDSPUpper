# AGC 与 AVC 配置页面使用体验优化

## 目标与范围

在现有上位机和 DataCenter 接口内优化控制配置流程，不修改下位机协议、控制算法或配置来源。用户已确认可以修改。包括弹窗高度、外部映射回显和编辑、AGC 总控输入选点、选点加载反馈、草稿保护、路由失败重试，以及实时数据时间和质量展示。

## 配置与映射

- 配置中的 tag 仍表示控制组本地点位；外部点身份使用模块、连接、tag 三元组，选外部来源不强制改写本地 tag。
- 增加统一映射区：输入字段选择数据来源，输出字段选择发送目标。查询既有路由回显；多个既有端点全部展示，不任意选择一个覆盖。
- 没有明确选择或修改绑定的字段不自动创建或删除路由。只同步用户明确编辑的字段；删除旧绑定前先新增新绑定，不使用整体替换全部路由，保留其他字段、其他控制组以及数据总线配置的无关路由。
- 同组端点禁止作为外部端点。连接或标签读取失败应显示可重试的错误，不能把失败伪装成空列表。
- AVC 保留原有成员快速选点与自动创建开关，作为兼容入口；明确其作用为成员草稿，最终保存控制组才下发。

## AGC 成员组内编辑（2026-10-12 确认）

- 用户先在协议配置中建立点位，再在控制组弹窗的成员区域新增或展开编辑成员；不再打开第二层成员弹窗。成员表与编辑区域在同一处，“完成成员编辑”只更新控制组草稿；最终“保存控制组并建立路由”统一校验并纳入当前正在编辑的成员，再下发配置与数据路由，避免要求用户先点一次暂存才能最终保存。
- 有功测量点和有功设定点直接选择现有外部点位，显示模块、连接、点名；不可控成员只选择测量点。移除成员的手工 tag、单位、缩放、偏移输入，也不提供这些字段的高级配置入口。工程量换算在协议点位流程中完成，协议测量与命令点应具备正确的 kW 工程量语义。
- 新建成员的内部测量和设定信号固定使用 kW、缩放 1、偏移 0；本地 tag 由系统生成，避开同组所有成员信号、增量基准和组输入输出 tag 的冲突。外部端点身份使用模块、连接、tag 三元组，不将外部 tag 当作内部 tag。
- 编辑旧成员时，没有明确更换点位的信号保持原有配置，包括精确 decimal 值和多个既有映射；不能只回显首个旧端点然后静默覆盖其他端点。明确更换测量点或不使用指定增量基准的设定点时，只替换该字段的映射，并将对应内部信号恢复为 kW、缩放 1、偏移 0；保持原有本地 tag，保留其他信号与路由。
- 历史指定增量基准（BASE_TAG）模式有兼容例外：下位机实际使用 p_set.signal 的 scale/offset 换算基准输入，绝对值输出不使用这组换算参数。因此，只更换设定输出而未更换基准输入时，必须保留旧 p_set.signal 的精确换算参数；明确更换到已为 kW 工程量的基准点时，才恢复这组参数为 kW、缩放 1、偏移 0。该处理由系统自动完成，界面不增加任何换算参数配置入口。
- 新成员必须选择测量点；可控新成员必须选择设定点。旧成员可以保留未更改的既有配置，但显式修改后的选择应有效。不可控成员不创建设定输出路由；由可控改为不可控时解除该成员旧设定与增量基准映射，其他字段不受影响。
- 成员名称、是否可控、容量、上下限仍是成员控制参数；调节权重只在自定义分配时出现。保留绝对值、增量值指令及其基准语义；旧增量基准不再使用时解除对应旧映射。
- 选择点位就建立绑定草稿，移除 AGC 成员的自动创建路由复选框。保存控制组后自动提交测量点到 AGC 的输入路由、AGC 到设定点的输出路由。显式换点先建立新路由，再解除旧路由，保留其他成员、其他控制组和无关的数据总线路由。
- 成员正在编辑时，刷新点位只更新可选点列表，保留编辑开始时的旧路由删除基线；不将其他操作新建且用户尚未确认的路由纳入删除计划。
- 保留成员未暂存改动与控制组未保存改动的确认保护；最终保存时若路由失败，应明确显示控制组已保存、绑定未完成，并保留完整计划供只重试路由，不能重复创建控制组。
- 验收覆盖新成员唯一 tag、同名与特殊字符成员、旧信号兼容、换点归一化、多个既有映射保留、不可控切换、正确路由方向和最终保存/失败重试时序；只在本地检查，不涉及部署或发布。

## 保存与恢复

- 配置和路由分阶段保存，不宣称跨模块事务。路由保存失败后保留待提交计划，显示配置已保存，提供只重试路由的按钮，不能以 createOnly 再次创建同名组。
- 路由重试必须幂等，明确区分新增失败和旧路由清理失败。读回映射失败时禁止提交依赖未知基线的映射修改。
- 待重试计划在当前页面会话中跨 AGC/AVC 切换保留，并同步异步重试结果；刷新或关闭页面前提示。计划不持久化到磁盘，重新加载页面后应通过已有路由核对结果。
- 配置和成员草稿有未保存改动时，关闭编辑提示确认；AVC 成员按钮为暂存成员，AGC 成员按钮为完成成员编辑，两者均只更新控制组草稿，仍需最终保存控制组。
- AGC 保存运行中的控制组前说明会停止控制组并在保存后恢复；AVC 继续遵循停止后编辑约束并显示原因。

## 实时值

- 查询成功不等于点值新鲜，使用点值 ts_ms 和质量判断。质量 0 为未指定，1 为有效，2 为无效，3 为不确定；未指定不等同于有效。
- 在运行监视中显示最新数据时间与陈旧、质量异常、缺点状态。时间未知不显示为最新；领先展示时钟超过一秒视为时间异常，一秒内的容差避免计时刷新误报。新鲜度只用于展示，不修改控制判断；按控制周期给出展示阈值并保留说明。
- 查询失败保留最后值但明确标识连接异常，不能继续显示正常。

## 布局与验收

- 兼容当前 Ant Design 的 ant-modal-container，并保留旧类兼容。标题、底部按钮固定在可视窗口内，正文独立滚动。
- 先补纯逻辑单元测试，覆盖稳定端点回显、明确修改字段的差异计算、一对多保留、清空绑定、失败重试幂等、时间过期与质量异常。
- 运行工作流测试、离线测试、类型检查和 lint；使用本地浏览器模拟页检查窄窗口弹窗、映射编辑和草稿保护。真机部署与联调不在本次范围。
