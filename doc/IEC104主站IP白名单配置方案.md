# IEC104 主站 IP 白名单配置方案

## 目标

IEC104 链路使用 `ROLE_SERVER` 监听时，上位机允许配置唯一可接入的主站 client IP，并通过现有 `LinkConfig.remote.ip` 下发给下位机。

## 配置语义

- `ROLE_SERVER`：显示“允许的主站 IP”，字段可为空；下发 `remote.ip`，并固定 `remote.port=0`。
- `ROLE_CLIENT`：继续使用“远程 IP”和“远程端口”作为连接目标，两个字段均必填。
- 服务端白名单留空、`0.0.0.0` 或 `::` 时，下位机兼容为允许任意来源；上位机表单当前按既有网络字段能力校验 IPv4。
- 编辑、复制、导入和导出连接配置时继续复用 `LinkConfig.remote`，不新增并行字段。

## 界面行为

- 新建服务端连接时白名单默认为空。
- 从客户端切换为服务端时保留远程 IP 作为白名单候选，但清空不参与服务端语义的远程端口。
- 连接详情对服务端展示“允许的主站 IP”；未设置限制时显示“任意来源”。

## 验收标准

- 服务端可以保存空白名单或合法 IPv4，并将其写入 `remote.ip`。
- 服务端不会把远程端口作为白名单条件下发。
- 客户端远程 IP 与端口的显示、校验和下发行为保持不变。
- 编辑既有服务端连接时能回显已保存的白名单 IP。
