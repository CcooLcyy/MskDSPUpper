# 下位机 gzip 安装包切换

用户已确认统一切换 gzip，不保留旧未压缩载荷兼容。

## 格式与接口

安装文件仍为可执行 Bash 脚本，`__ARCHIVE_BELOW__` 后仅允许 gzip 镜像 tar。`start` 命令、更新清单 schema、镜像 config ID 和现有业务配置语义保持不变。旧裸 tar、整文件 `.gz` 及损坏的压缩载荷不能作为可下发安装包。

本地导入流式读取 gzip 内 tar 元数据，保留原有路径、重复条目、平台和 Docker/OCI 摘要关联校验，最大解压总长度为 4 GiB，必须读至压缩流结束验证 CRC、长度和尾部，禁止多成员或尾随字节。不会将完整镜像解压到内存或磁盘。

在线下载、缓存和上传保持压缩包原始字节。下载校验最终包大小与 SHA256，再验证脚本分界后的 gzip 格式；缓存恢复和上传前执行同样的格式检查。整个安装文件直接 gzip 后无法执行，明确不支持。

## 缓存与切换

缓存元数据版本升级为 2。启动时清理旧版本、无有效元数据或格式错误的下位机安装包缓存，包括本地导入缓存；保留当前版本对应的 gzip 安装包与元数据，清理范围只在专用下位机更新缓存目录内。

推荐先发布新上位机，再发布压缩下位机包；新版上位机遇到历史未压缩包提示重新下载。在线与离线使用同一新格式，不自动解压后上传，不修改现场配置。

## 验收

- Docker/OCI 两种 tar 布局、ARM64/x64 平台的 gzip 本地导入均保持正确身份。
- 拒绝裸 tar、整包 gzip、CRC 错误、截断、压缩尾随内容和非法元数据；大镜像条目流式跳过且有总量限制。
- 旧缓存清理、新缓存保留、下载验证失败不覆盖已有包、上传前拒绝旧包并保持字节透传。
- Python/Bash 隔离安装测试、Rust 测试与前端相关回归通过。真机性能与实际 Docker 加载仍需在明确设备范围后验证。

完整下位机方案见配套仓库 `MskDSP/doc/下位机压缩安装包方案.md`。
