# AVC 成员配置与 AGC 统一方案

## 目标与范围

沿用 AGC 的控制组成员列表、独立成员弹窗、已有点位选择与最终保存流程。仅修改上位机，不修改下位机协议、控制算法或发布版本。

成员常用配置为名称、是否参与控制、无功测量点、无功设定点、无功上下限（kVar）和自定义分配权重。绝对/增量指令及增量基准归入更多控制参数。无功上下限允许负数，要求下限不大于上限，按可调范围分配的可控成员要求上限大于下限。

组级保留目标电压/总无功二选一、母线电压测量、电压比例系数与死区、控制方式与周期。周期直分配仅支持总无功模式。组级输入采用已有点位绑定；内部 tag 与已有映射在未明确修改时保持原样。

## 输入输出与保存规则

- 选项来自 DataCenter 已登记连接及点位；外部端点由模块名、连接名和 tag 唯一确定，不直接复用外部 tag 作为新成员内部 tag。
- 新成员自动生成同组唯一内部 tag，无功采用 kVar 工程量、恒等换算。协议点表负责新增绑定的工程量换算与读写配置。
- 已有成员未换点时保留原内部 tag、换算参数、命令语义及全部已有绑定；只替换明确修改的绑定。旧指定基准点的换算在仅换设定输出时保持。
- 未修改的数值保留旧 Decimal20 精度文本；修改数值或显式切换分配方式时同步对应精度文本，防止下位机继续使用旧值。
- 成员确认仅写入控制组草稿；取消成员或控制组不调用配置与路由写接口。成员弹窗开启时阻止父弹窗保存和关闭。
- 保存控制组时统一保存配置，增加新绑定并清理被替换或废弃的旧绑定。删除成员、改为仅测量或取消指定增量基准时仅清理对应字段路由，保留其他成员和其他组路由。
- 去除重复的快速回填及自动创建路由开关，选点即形成待保存绑定。已有无映射配置仍可查看和仅编辑参数；新成员或明确换点必须有对应端点。
- 映射加载失败时禁止保存；刷新选项保留编辑期间基线。配置保存成功而路由失败时保留完整差异计划，通过现有页面重试入口只重试路由。
- 切换组命令模式或本地 tag 的隐式清理只作用于当次保存计划，配置保存失败后切回原模式不改变原绑定草稿。

## 验收与验证

先补失败测试，再实现绑定规则。覆盖内部 tag 冲突、负无功范围、旧换算与多端点保留、精确换点、旧基准换算、关闭控制/切换基准/删除成员清理、路由方向与失败重试。

执行相关工作流与离线回归、TypeScript 构建及 lint。通过浏览器演示数据检查新增、编辑、取消、最终保存、模式切换和刷新，确认界面布局与现有 AGC 一致。离线适配器由回归测试验证；浏览器演示不连接真机，真机联调不在本次范围内。

本次验证结果：工作流 402 项、离线 74 项通过；构建及严格 lint 通过。新增绑定、高精度数值和临时清理测试均先失败再通过。浏览器演示完成成员新增选点、重复编辑回显、取消数值改动、最终保存两条路由、刷新映射与目标电压模式禁用周期直分配检查。构建仍提示既有的大体积资源分块警告。
