# IEC104 手动选点模拟

## 已确认需求与边界

允许直接选择单个或多个点并手动输入临时模拟值，不要求先生成整批模拟数据。只有保存时勾选的点进入模拟快照，其余点继续原有数据路径。本功能与持久化“固定上报值”分别管理，不修改点表、路由、倍率偏移或固定上报配置。

## 交互与接口

- 模拟数据窗口保留现有随机、递增、遥信生成方式，增加“手动选点”入口。
- 编辑窗口展示 IOA、Tag、类型以及模拟值。FLOAT 输入工程量数值，SINGLE 选择 0/1；已启用固定上报值或非遥测/遥信的点不参与选择。
- 新建编辑草稿使用现有模拟快照；没有快照时可以直接选点输入。未填写的点不默认为 0；合法的 0 和 false 必须保留。
- 仅勾选的点提交；保存会完整替换该连接的模拟快照，取消勾选即退出该点模拟。全部退出使用已有“清除模拟值”。草稿编辑不影响运行值，关闭窗口丢弃未保存修改。
- 适配器新增 `iec104SetSimulationValues(connName, points)`，桌面命令 `iec104_set_simulation_values` 直接调用 IEC104 模块的 `SetSimulationValues` RPC。请求 `SetSimulationValuesRequest { conn_name, repeated SimulationPoint points }`，响应 `SimulationSnapshot`。
- 请求只使用 Tag、点位类型及对应值；后端统一设置品质和时间。后端先校验完整列表再替换，失败时原有快照不变。
- 保存立即更新模拟快照和运行视图；主动发送仍由“应用并发送”触发。工程量沿用模拟值的倍率/偏移换算，与直接指定报文数值的固定上报功能保持各自语义。
- 连接切换、异步返回、重复提交需沿用现有运行操作保护；离线工作区不提供运行态模拟操作。旧下位机返回未实现接口时，显示错误并保留原快照。

## 周期上报扩展（2026-10-23）

模拟数据窗口增加周期上报开关、1～3600 秒的间隔（默认 5 秒）、运行状态和最近周期发送时间。任务由下位机 IEC104 模块执行，仅重复发送当前模拟快照；手动保存或重新生成后下个周期使用新值。关闭窗口不停止任务，断线暂停、传输激活后继续，清除模拟值自动关闭；模块重启后默认关闭。旧模块未实现接口时提示升级，原有模拟操作继续可用。

上位机直接调用 `SetSimulationPeriodicReport` 和 `GetSimulationPeriodicStatus`，运行态不进入离线配置。详细接口、边界与验收见下位机仓库 `doc/IEC104模拟值周期上报方案.md`。

本地验证：工作流 498 项、离线 110 项、周期设置 Rust 4 项和原手动模拟 Rust 5 项通过，构建、严格 ESLint 通过。浏览器内存适配器验证开启、关窗继续、断线恢复、空白间隔仍可关闭和清除自动关闭；未连接设备或部署。下位机新增测试尚未编译运行，不能据此声称实际周期报文已验证。
