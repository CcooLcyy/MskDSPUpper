# Modbus 点表模板界面预览

界面确认后已接入正式模板组件和 PDF 点表；此入口可独立试用正式模板的选择、导入、导出及个人模板保存。

运行已有 `npm run dev -- --host 127.0.0.1`，打开 `/modbus-template-preview.html`。
此入口独立于正式 App 与更新 Provider，初始化现有上位机设置，用于持久化个人模板。
试用连接与点表仅存在于 React 内存中，刷新恢复初始状态，不访问设备。
内置模板为用户提供 PDF 整理的真实点表，适用条件及排除范围见模板说明和核对文档。

验收操作：
- 初始连接点表为空，可以新建 RTU/TCP 连接，分别应用模板。
- 模板支持厂家筛选、搜索、切换和点位筛选；默认选中全部，支持仅选筛选结果。
- 设置标签前缀后，预览最终标签；已有标签或寄存器范围重叠的点位提示冲突并跳过。
- 应用后显示点位；重复应用不会覆盖；取消不改变点表。
- 点位可修改标签或删除，连接间点表独立，重置可重新体验。
- 弹窗信息、筛选区和底部按钮固定；点表按剩余高度独立滚动，模板列表在空间不足时独立滚动。
- 正式产品已接入 RTU/TCP 页面；本试用入口不发送设备请求，个人模板保存、导入和删除会修改本地模板库。
