# 平台登录切换账号

- 主动退出只需一次确认：提示未保存内容会丢失，关闭自动登录，退出平台会话并清理连接，重新加载工作台后直接显示可编辑账号的普通登录页。无需重启上位机进程。
- 会话到期或被撤销时仍锁定并保留当前账号草稿；原账号重新登录可以继续。锁定页提供“退出并更换账号”，一次确认后执行相同退出流程。
- 退出前同步检查设备升级、上位机更新等不能中断的任务；不允许退出时保留当前工作台和认证状态，显示中文原因。
- 确认退出后先同步锁定并使旧响应失效，再依次保存关闭自动登录的偏好、退出原会话、清理后端连接并重建前端。保留已保存的配置、账号和记住密码偏好，账号变化时清空旧密码。
- 前端通过重新加载页面清理页面草稿、Provider、全局缓存和监听；重建完成前保持旧工作台锁定，避免新账号继承旧账号状态。
- 退出期间禁止重复提交、登录和保存设置。保存偏好、退出或重建失败时显示中文错误，保留草稿锁定且允许重试，不提前允许其他账号登录。
- 设备选择按连接代次校验并与退出清理共用发布锁，拒绝退出前发起的旧选择请求及已失效连接，避免重新加载页面后残留原账号设备。

验收覆盖：主动退出后重新初始化新账号、过期和撤销后原账号恢复草稿、关闭自动登录、各阶段失败重试、升级任务拦截、重复请求及晚到响应/凭据；执行前端构建和静态检查。安装版页面重载和连接清理仍需桌面验证。

本地验证（2026-10-23）：offline 110 项、workflow 492 项及 Rust 库测试 235 项通过；生产构建、严格 ESLint、变更 Rust 文件格式检查通过。Edge 浏览器使用模拟平台接口验证 4 条流程：主动退出后登录其他账号且草稿隔离、会话失效后原账号恢复草稿、升级任务阻止退出、锁定页确认可取消和执行；锁定时普通业务弹窗仍隐藏，页面无未捕获异常。未更新已安装桌面程序，未连接真实平台或设备。
