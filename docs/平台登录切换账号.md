# 平台登录切换账号

- 退出登录或会话失效后，继续保留当前账号的工作台草稿；原账号重新登录可恢复。
- 锁定页提供“切换账号”入口，先提示重启上位机并放弃未保存的页面草稿；取消不改变当前状态。
- 确认后，先保存关闭自动登录的偏好，再退出旧平台会话，最后重启上位机。保留已保存的配置、账号及记住密码偏好；重启后的账号框可编辑，修改账号会清空旧密码。
- 使用完整进程重启清理页面、模块缓存及后台连接，避免新账号继承旧账号的内存状态。
- 切换只允许在工作台锁定且没有登录、退出或保存请求时执行；操作期间禁止重复切换和登录，丢弃晚到的会话与密码读取结果。
- 保存偏好、退出或重启失败时，显示中文错误，保留旧草稿及账号锁定，允许重试；不得提前开放其他账号登录。

验收覆盖：原账号恢复草稿、关闭自动登录后才重启、偏好/退出/重启失败、重复请求及晚到响应；另执行前端构建和静态检查。桌面进程重启需在安装版中验证。
