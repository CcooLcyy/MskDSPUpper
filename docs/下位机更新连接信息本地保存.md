# 下位机更新连接信息本地保存

## 目标与边界

用户确认在上位机的下位机更新页面中，成功下发一次之后记住目标连接信息。此次仅修改 Windows 上位机，不部署设备、不改变下位机配置。SSH 密码和独立 sudo 密码交由 Windows 凭据管理器加密保存，不进入普通设置文件、工作区导出或日志。

## 保存与恢复

- 首次成功上传更新包或成功安装之后，保存实际请求中的上传账号、安装目录、SSH 认证方式、sudo 密码复用开关和记住密码开关。
- 普通字段使用现有本地 settings.json 的独立设置项 `mskdsp_lower_update_connection`。后端仅接受规定字段，拒绝密码等额外字段，校验账号、绝对安装路径和认证方式。
- SSH 与独立 sudo 密码以不同服务名、相同规范化的 user@host:port 为索引保存到 Windows 凭据管理器。
- 默认开启记住密码；关闭时不自动恢复密码，成功下发后清除该目标已保存凭据。证书模式不保存 SSH 密码；复用模式不重复保存 sudo 密码。
- 进入页面恢复最近成功的连接信息。切换上传账号或认证方式时先清空原密码，异步读取结果仅应用于当前目标；不得把设备 A 的密码带到设备 B。
- 去掉更新页面硬编码的默认密码。保留现有 SSH 凭据读取和迁移能力，但 SSH 建连本身不再无条件保存密码。
- 提供清除当前目标已保存密码入口，清除 SSH、sudo 及匹配的旧版凭据；清除后关闭记住密码，避免自动保存回去。
- 清除成功后，仅当该目标已有成功保存的连接设置时持久化关闭记住密码；不得借清除操作创建未验证的目标配置。
- 同一目标的保存与清除使用跨页面共享的串行队列和撤销代次。清除时立即撤销旧任务：已开始的保存先完成再清除，尚未执行的旧成功回调跳过保存。部署及保存期间禁用当前页面的目标、认证与记住/清除控件。

## 接口

- `get_lower_update_credentials(upload_account)` 返回当前目标的 `ssh_password`、`sudo_password` 可选值。
- `save_lower_update_connection(settings, auth, sudo_password)` 在成功下发之后调用。settings 字段为 `upload_account`、`install_dir`、`auth_method`、`reuse_ssh_password_for_sudo`、`remember_password`；auth 沿用现有 SSH 认证 DTO。
- `clear_lower_update_credentials(upload_account)` 清除当前目标的全部更新凭据。

## 连接地址历史

- 上传账号支持自由输入与下拉选择；记录成功上传或成功安装的地址，失败操作和单纯编辑不加入历史。
- 新增本地设置 `mskdsp_lower_update_connection_history`，最多保留 20 条非敏感连接配置，最近成功使用的地址排在最前。与 Windows 凭据索引一致，规范化端口并按 ASCII 大小写不敏感去重，实际登录账号保留原大小写。
- 兼容已有的最近一次连接设置：缺少历史时将旧设置作为首条记录。成功保存时一起更新最近设置与历史，避免部分写入。
- 选择地址恢复该记录的安装目录、认证方式、sudo 复用和记住密码选项；先清空密码并使旧异步读取失效，再读取该目标的加密凭据。历史不包含 SSH 密码或 sudo 密码。
- 清除密码保留历史地址及排序，只关闭对应历史记录的记住密码选项；不得修改其他地址的配置。
- 验收覆盖旧设置迁移、多地址去重排序、20 条上限、敏感字段过滤/拒绝、持久化重读、清除非最近地址及页面历史选择。

## 异常与验收

- 失败的上传/安装不得覆盖上一次成功配置；并发操作必须保存实际成功请求，不能保存用户之后编辑的表单内容。
- 配置或凭据保存失败时明确提示“下发成功但保存失败”，不将已成功的更新操作改判为失败。日志仅记录操作与目标，不记录密码。
- Windows 凭据管理器与普通设置文件不支持跨存储原子事务；部分凭据更新后失败会返回保存失败提示，原有成功设置保持不变，用户可重试或清除。
- 测试覆盖配置校验、额外敏感字段拒绝、配置读写、凭据隔离与清除逻辑，以及记住开关、复用规则、异步读取竞争和成功回调集成。
- 执行相关前端测试、类型检查、lint 和可用的 Rust 检查；真实 Windows 凭据库验收不使用真实设备密码，不为测试触发真实设备更新。
