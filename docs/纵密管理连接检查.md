# 纵密管理连接检查

## 目标与范围

直连检查固定访问 `11.22.33.44:8888`。检查电脑维护网卡和最佳路由后，依次报告 ICMP、TCP 管理端口、TLS 握手结果。仅网卡、路由、TCP 和 TLS 均通过时显示“管理连接可用”；ICMP 无响应只作诊断信息，不阻止实际管理连接检查。

TLS 与实际纵密登录共用证书配置、自动匹配候选、信任校验和限定旧版兼容策略。检查不发送账号或业务命令，不创建登录身份，不修改设备网络配置；检查流在完成或超时后释放。TCP 拒绝、TCP 超时、TLS 超时、证书错误分别展示，后续未执行阶段不得显示成功。平台远程访问继续保留未支持状态。

同一上位机进程只允许一个管理连接探测。页面取消会立即丢弃该次结果，后台探测继续到完成或超时并释放连接；其间再次检查明确提示“上次管理连接检查尚未结束，请稍后重试”，不建立重叠探测连接。

## 结果有效性

结果返回完成检查的 Unix 毫秒时间 `checked_at_ms`，页面显示本地时间并说明这是该次检查结果。后续实际登录的连接或 TLS 阶段失败时撤销此前通过结果；身份认证失败不等同于管理连接不可用。过期异步检查结果不得覆盖取消、后续登录失败或更新后的检查结果。

## 验收

- ping 成功但端口拒绝时，整体失败，明确端口拒绝，TLS 未执行。
- TCP 成功但 TLS/证书失败时，整体失败，保留 TCP 成功诊断。
- ICMP 无响应但 TCP、TLS 成功时，管理连接可用，同时保留 ICMP 提示。
- 证书选择与登录相同，TLS 探测不发送认证材料，不保留登录会话。
- 显示检查时间；登录连接失败撤销旧通过结果，账号错误不错误撤销连接结果。
- 网卡、路由不合格时不建立管理连接；远程不支持时不探测目标。

先使用本地单元测试和受控流验证失败路径、超时、证书候选及释放行为，再运行相关回归、类型检查与构建。真机观察仅作为现场证据，不代替失败场景测试；本次不部署或覆盖正在运行的上位机。
