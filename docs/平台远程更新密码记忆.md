# 平台远程更新密码记忆

用户确认在下位机更新页面支持“在本机记住密码”，按设备和 SSH 用户匹配。此次只改上位机，不部署或更新设备。

- 首次无记录时关闭记住密码，用户勾选后，仅在成功下发安装包后保存实际请求中的凭据。
- 索引包含规范化的平台地址、设备唯一 ID、SSH 用户名。设备改名或现场 IP 改变不影响匹配；平台、设备或 SSH 用户不同则分别保存。设备 ID 和用户名区分大小写。
- 使用独立的 Windows 凭据管理器条目保存 SSH 密码、sudo 复用选项和独立 sudo 密码，不写入普通设置、历史、工作区导出或日志。复用时不重复保存 sudo 密码。
- 进入页面自动读取当前目标的凭据。切换设备或用户先清空原密码；过期读取不得覆盖新目标或用户已经编辑的字段。
- 页面提供“已记住密码”提示、“更换密码”和“清除已保存密码”。关闭记住密码立即删除当前目标的记录，保留正在编辑的密码以供本次任务使用；显式清除同时清空密码框。
- 保存和清除按目标串行执行，并使用撤销代次防止旧任务重新写回已清除的密码。保存失败单独提示，不把成功下发改判为更新失败。
- 认证失败保留可编辑的密码框，用户可更换密码重试；失败请求不得覆盖上一次保存的凭据。
- 浏览器开发模式不提供密码持久化，也不以明文存储模拟加密凭据。

验收覆盖不同平台、设备、用户及大小写隔离，SSH/sudo 往返读取，默认关闭、自动回填、更换和清除，用户输入与异步读取竞争，失败不保存，以及清除与旧成功回调的竞争。测试使用虚构凭据，不触发设备更新。
